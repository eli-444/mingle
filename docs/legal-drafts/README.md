# Textes fournis renommés

Les trois fichiers `.txt` conservent les textes anglais fournis par l’utilisateur, avec le nom Mingle TV, le domaine mingletv.app, Aurora Web & Security et aurorawebsec@gmail.com. L’adresse de l’ancienne société est remplacée par un champ à compléter. L’ancienne plage d’années est remplacée par 2026, sans prétendre que Mingle TV existe depuis 2015.

Ce sont des brouillons de comparaison, exclus du site et du build Vercel. Ils décrivent encore des fonctions absentes : application mobile, comptes sociaux, paiements, prestataires de vérification d’âge, captures de signalements, modération continue, bannissements automatiques. Les chemins hérités `/support`, `/account-deletion` ou de remboursement ne sont pas des fonctionnalités de Mingle TV. Le remplacement du nom ne rend pas ces clauses exactes ni juridiquement adaptées.

Les versions françaises intégrées au site se trouvent dans `public/terms.html`, `public/privacy.html` et `public/rules.html`. Elles reprennent les thèmes utiles des documents fournis en décrivant le code actuel : accès sans compte, majorité déclarative, absence de paiement et d’enregistrement vidéo, traitement manuel des signalements, restrictions IP temporaires et statistiques facultatives de visiteurs distincts.

L’identité et l’email sont ceux fournis par l’exploitant. Il reste à compléter son adresse, ses mentions d’identification selon son statut, les hébergeurs effectifs, les transferts et les durées des logs, emails et sauvegardes. Les textes ne valent pas validation juridique du lancement.
